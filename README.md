# A KernelSU module to improve RAM management
> ⚠️ **IMPORTANT:** This module is designed specifically for the **Xiaomi Mi 9 running crDroid 12.11, AxionOS 2.8, and Infinity X 4.1**. Don't expect the same functionality, performance, or results on other devices or ROMs.

## What This Module Does :
#### Modify Virtual Memory settings
#### Customize How Low Memory Killer Daemon (LMKD) Works
#### Change ZRAM size

## These options are only available in the module for crDroid :
### ⚖️BALANCED :
Designed for better multitasking performance.

### 🚀PERFORMANCE :
More aggressive at freeing RAM.
